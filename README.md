# Go Cash

Página inicial simples para uma marca de educação financeira e gestão de dinheiro.

## Como visualizar localmente

1. Abra a pasta do projeto.
2. Clique no arquivo `index.html`.
3. Ou rode um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos do projeto para o repositório.
3. Vá em `Settings` > `Pages`.
4. Em `Source`, selecione a branch principal e a pasta raiz.
5. Salve.
6. O GitHub vai gerar um link público do tipo:

```text
https://seu-usuario.github.io/seu-repositorio/
```
